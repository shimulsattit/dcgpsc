===========================================================
        SCHOOL PROJECT - TERMINAL COMMANDS GUIDE
===========================================================

১. প্রজেক্ট ফোল্ডারে প্রবেশ করা (Go to project directory):
-----------------------------------------------------------
cd c:\laragon\www\dhaka_cant_girls


২. নতুন স্কুলের জন্য প্রজেক্ট ক্লিন এবং রিসেট করা:
-----------------------------------------------------------
এটি সব ডেমো ডাটা মুছে ফেলবে এবং ডিফল্ট সেটিংস সেট করবে।
(This will clean demo data and set professional defaults)

php artisan app:school-init


৩. ক্যাশ এবং ভিউ ক্লিয়ার করা (যদি কোনো পরিবর্তন না দেখা যায়):
-----------------------------------------------------------
php artisan optimize:clear


৪. নতুন এডমিন ইউজার তৈরি করা (প্রয়োজন হলে):
-----------------------------------------------------------
php artisan app:create-admin-user


৫. ড্রাইভ কানেকশন টেস্ট করা (OAuth2 Test):
-----------------------------------------------------------
php scratch\test_oauth.php


৬. স্টোরেজ লিংক তৈরি করা (যদি ছবি না দেখায়):
-----------------------------------------------------------
php artisan storage:link


===========================================================
        LIVE SERVER GUIDE (cPanel/VPS)
===========================================================

১. সার্ভারে ঢোকার পর প্রজেক্ট ডিরেক্টরিতে যান:
-----------------------------------------------------------
cd path/to/your/project


২. প্রয়োজনীয় প্যাকেজ ইন্সটল করা:
-----------------------------------------------------------
composer install --no-dev


৩. ডাটাবেজ টেবিল তৈরি করা (Migration):
-----------------------------------------------------------
php artisan migrate


৪. প্রজেক্ট সেটআপ এবং ক্লিন করা:
-----------------------------------------------------------
php artisan app:school-init


৫. পারমিশন ঠিক করা (যদি এরর দেখায়):
-----------------------------------------------------------
chmod -R 775 storage bootstrap/cache
